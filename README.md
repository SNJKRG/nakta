# NAKTA: сайт ресторана

Vite + React + TypeScript. Две страницы: главная `/` и меню `/menu/`. Ссылку `/menu/` можно ставить в QR-код на столе, а `/menu/#steyki` открывает сразу нужный раздел.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Деплой: Vercel, Framework = Vite.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `src/menu-data.ts` | Все блюда, цены, состав и фото категорий |
| `src/content.ts` | Телефоны, WhatsApp, адрес, часы, залы, блюда для главной |
| `src/Home.tsx` | Главная: блюда, залы, история, запрос стола, контакты |
| `src/MenuPage.tsx`, `src/menu-ui.tsx` | Меню: поиск, разделы, карточка блюда, «Собрать дасторкан» |
| `src/Hero.tsx`, `src/hero.css` | Первый экран с видео; делался отдельно |
| `src/styles.css` | Цвета, шрифт и все стили |

## Что сделать ресторану перед публикацией

1. **Цены и меню.** Меню перенесено из копии «Nakta 2026111» на Scribd (28 страниц). Её загрузил сторонний пользователь, дата цен неизвестна. Нужно сверить каждую цену с действующим меню. Сомнения в источнике:
   - В «Куурдаке из телятины» описание говорит о баранине. На сайте оставлено нейтральное «жареное мясо».
   - Цены поштучных шашлыков сопоставлены по порядку в тексте документа.
   - «Пирамида, 10 шт / 6 шт» в меню без описания.
2. **Чего нет на сайте.** Напитки (вода, соки, айран, чалап, компот) и услуги (варка мяса, теста, таш-кордо) не перенесены: в копии цены не однозначно привязаны к позициям. Вес порций указан только там, где он есть в меню.
3. **Часы работы.** 11:00–00:00 взято с Restaurant Guru, где показан только один день недели. Нужно подтвердить, что это расписание на каждый день.
4. **Адрес.** На сайте указан «Кок-Жар, ул. Мадиева, 71А» (публикация ресторана в Instagram). На странице в Facebook указан адрес «Курманжан Датка, 305». Нужно подтвердить, какой адрес актуален и нет ли второго заведения.
5. **WhatsApp.** Запрос стола уходит сообщением на +996 557 73 55 77. Нужно проверить, что на этом номере есть WhatsApp и его читает администратор. Номер меняется в `src/content.ts`.
6. **Залы.** «Зал с росписью и коврами» и «Зал с горным пейзажем» — описания по фотографиям, а не официальные названия. Из подтверждённого есть только диапазон «банкетные залы на 5–110 персон» из профиля ресторана. Нужны настоящие названия, вместимость каждого зала и фото террасы, если она работает.
7. **Фотографии.** Снимки с Restaurant Guru очищены от наклеек с помощью ИИ: закрытые участки дорисованы, права на фото не подтверждены. Фото из Instagram маленькие (360 × 640). Лучше заменить всё оригиналами съёмки ресторана.
8. **Логотип.** SVG в `src/emblem.svg`, `src/wordmark.svg`, `src/lockup.svg` и `public/favicon.svg` — векторная реконструкция по аватарке Instagram размером 150 × 150 px, а не мастер-файл бренда. Надпись восстановлена шрифтом, похожим на Times New Roman Bold. Нужен оригинальный вектор.

## Решения по дизайну

- **Шрифт.** Kurale везде, одно начертание. Иерархия строится размером и цветом; искусственный жирный отключён через `font-synthesis: none`. Кыргызские Ө Ү Ң в шрифте есть.
- **Цвета.** Крем `#F3E9DA` — фон, шоколад `#391B11` — заголовки и тёмные секции, бордо `#5D1C22` — действия, охра `#AE832F` — только орнамент. Значения взяты из `nakta-assets/palette.json`.
- **Фото и подписи.** Фото с названием блюда стоит только там, где блюдо однозначно видно: боорсоки. Остальные снимки подписаны тем, что на них изображено, или служат обложками разделов.
- **Дасторкан.** Выбор блюд хранится в `localStorage` браузера. Обслуживание 15% показано отдельной строкой. Это подборка для визита, а не заказ.
- **Бронь.** Сайт не подтверждает бронь сам. Форма готовит сообщение в WhatsApp, подтверждает администратор.
- **Язык.** Сайт на русском. Кыргызский и английский можно добавить отдельной задачей.
